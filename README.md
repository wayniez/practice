# 🧠 ML Practice

A collection of hands-on Jupyter Notebook exercises covering core machine learning algorithms and techniques.

## 📂 Contents

| Topic | Description |
|---|---|
| [`linear_regression`](./linear_regression) | Predicting continuous values with linear models |
| [`logistic_regression`](./logistic_regression) | Binary and multiclass classification |
| [`decision_trees`](./decision%20trees) | Tree-based decision making |
| [`decision_trees_practice`](./decision_trees_practice) | Additional decision tree exercises |
| [`random_forest`](./random_forest) | Ensemble learning with random forests |
| [`boosted_trees`](./boosted_trees) | Gradient boosting methods |
| [`clustering`](./clustering) | Unsupervised learning and cluster analysis |
| [`cross_validation`](./cross_validation) | Model evaluation and validation techniques |
| [`feature_engineering`](./feature_engineering) | Data preprocessing and feature transformation |

## 🛠️ Stack

- **Python** — primary language
- **Jupyter Notebook** — interactive environment
- **scikit-learn** — ML algorithms
- **pandas / NumPy** — data manipulation
- **Matplotlib / Seaborn** — visualization

## 🚀 Getting Started

```bash
git clone https://github.com/wayniez/practice.git
cd practice
jupyter notebook
```

## 📌 Goal

Working through practical ML implementations — from fundamentals like linear regression to ensemble methods like gradient boosting — to build intuition and hands-on experience with real datasets.
